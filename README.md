# Nikel
Projeto de Desenvolvimento do curso Codaí 2.0 - Front-End da Growdev

## 🚀 Ambiente de Desenvolvimento: GitHub Codespaces

A escolha por utilizar o **GitHub Codespaces** como ambiente principal de desenvolvimento para este projeto foi motivada pela necessidade crítica de **portabilidade**.

O desenvolvimento é frequentemente realizado em diferentes computadores que não são de propriedade do desenvolvedor. O uso do Codespaces resolve este desafio ao:

1.  **Eliminar a Configuração Local:** Não é necessário instalar o Node.js, Git, ou qualquer outra ferramenta em cada máquina. Basta um navegador para ter acesso ao ambiente completo.
2.  **Garantir Consistência:** O ambiente de desenvolvimento, incluindo todas as extensões do VS Code e versões de software (definidas no `.devcontainer`), é idêntico em qualquer lugar.
3.  **Centralizar o Projeto:** Todo o código, dependências (`node_modules`) e configurações ficam na nuvem, atrelados ao repositório, e não espalhados por diversas máquinas locais.

Isso garante que o projeto possa ser acessado e continuado de forma produtiva e segura, independentemente do computador físico disponível.
